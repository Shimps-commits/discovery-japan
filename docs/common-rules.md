# Discovery Japan 共通ルール（全地域サイト共通）

Discovery Japan シリーズの、すべての地域サイトで守るルール。
地域ごとの内容（出羽島だけの注意など）は、各リポジトリの CLAUDE.md に書く。
新しい地域サイトは、このファイルをそのままコピーして始める。

---

## 1. 文章のルール

- 本文は必ず「だ・である」調で書く。「です・ます」は使わない（見出し、ボタン、注釈も含む）。
- シリーズ名は **Discovery Japan**（Japan Discovery は使わない）。
- 地域名の英語表記はローマ字で統一する（例: Teba-jima, Kaiyō, Mima, Shiramine, Obuse）。
- 次の言葉は使わない: 「観光」「攻略」「予定がない」。
- 日本語と英語は必ず対になるように書く（`data-l="ja"` / `data-l="en"`）。
- 小さい見出し（キッカーやラベル風の小さな文字の見出し）は付けない。

### シリーズのタイトル形式

- 形式: `Discovery Japan “○○” vol.○` ＋ ローマ字の地域名
- vol.1 Ocean / Teba-jima / 出羽島　海と共に暮らす（四国・徳島）
- vol.2 Organic / Kaiyō / 海陽町　土と共に暮らす（徳島）
- vol.3 Spirit / Mima / 美馬　精神世界と共に暮らす（徳島）
- vol.4 Forest / Shiramine / 白峰　山と共に暮らす（石川）
- vol.5 Art / Obuse / 小布施　芸術と共に暮らす（長野）

## 2. デザインのルール

基本は、ごーへいデザインシステム（https://claude.ai/artifact/17YcUZneGLiM66EGFEbxGp）に従う。
ただし、色と書体は下の値を基準にする。

- モーションは、スクロールに連動した表示（`.rv`）だけ使う。
- 魚の動き、カーソルへの追従、傾きのインタラクションは入れない。
- BGM のオン・オフ（♪ボタン）は、常に表示する。

### 色（CSS 変数）

| 変数 | 値 | 用途 |
|---|---|---|
| `--obsidian` | `#000000` | 背景（基本の黒） |
| `--paper` | `#ffffff` | 本文の文字 |
| `--deep-current` | `#031e25` | 深い海の紺（アクセント用の背景） |
| `--slate-depth` | `#1d1d1e` | カードや図版の背景 |
| `--charcoal` | `#0a0a0a` | 予備の黒 |
| `--bone` | `#e5e7eb` | 明るいグレー（補助） |
| `--muted` | `rgba(255,255,255,0.72)` | 補助的な本文 |
| `--line` | `rgba(255,255,255,0.16)` | 罫線 |

- 基本は黒背景に白文字。白背景は使わない（ギャラリーも黒背景）。
- 色は上の変数を使い、直接の色コードを増やさない。

### 書体

- 欧文・数字: Inter
- 和文: Noto Sans JP
- 見出し（h1, h2）: weight 300
- 本文: weight 300〜400
- ナビ・ボタン・ラベル: weight 500、大文字、letter-spacing 0.2〜0.24em

Google Fonts の読み込みは、次の指定を使う:
`Inter:wght@300;400;500` と `Noto+Sans+JP:wght@300;400;500`

### サイズと余白

- 左右の余白: `clamp(20px, 4.2vw, 64px)`
- 最大幅: 1440px
- h1: `clamp(52px, 11vw, 188px)`、line-height 0.92、letter-spacing -0.055em
- h2: `clamp(30px, 5vw, 76px)`、line-height 1.18、letter-spacing -0.03em
- 本文の line-height: 1.8
- カードの角丸: 32px
- イージング: `cubic-bezier(0.19, 1, 0.22, 1)`

### レイアウト

- ナビは上部に固定。左にサイト名（大文字）、右に JA / EN / ♪。
- 見出しの後、本文・写真・動画の順で置く。
- 写真や動画は、画面幅いっぱいか、大きな角丸のカードで見せる。
- スマホ（幅390px）と PC（幅1440px）の両方で確認する。横スクロールが出ないこと。

## 3. 動画・音声・写真

- 動画: h264 の無音ループ。表示されているときだけ再生する。
- BGM: その地域用に用意した楽曲（`img/bgm.mp3`）だけを使う。波の音は入れない。
- BGM は、ページ読み込み時に再生を試み、最初のタップで再生を開始する（ブラウザの仕様）。
- 写真は、軽くするためにリサイズして入れる。
- 使っていない画像は、コミット前に削除する。

### 人物の掲載

- 人物の名前や写真を載せるときは、必ず本人の了承を確認する。

## 4. 作業の手順

1. そのリポジトリで変更する。
2. ローカルか、スマホの幅で表示を確認する（横スクロールが出ないこと）。
3. `main` にコミットして push する。GitHub Pages が数分で反映する。
4. 公開後、シークレットウィンドウ（ログインしていない状態）でURLを開き、表示を確認する。

- ログインなしで見られることが大切。claude.ai のアーティファクトのリンクは使わない（ログインが必要になるため）。
- ページ同士のリンクは、相対パス（`gallery/`、`../`）で書く。

---

## 5. 質問の仕方

- 確認が必要なときは、選択肢（多肢選択）で聞く。自由記述の質問は避ける。
- 方針を決める前に、大きな変更は必ず確認する。
